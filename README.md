# Play to Prevent Cyberbullying

A short reveal.js slide deck on preventing cyberbullying through play.

## View locally
```
python3 -m http.server 8080
```
Open http://localhost:8080. Arrow keys navigate, `S` opens speaker notes, `F` is fullscreen, `Esc` shows the slide overview.

## Publish on GitHub Pages
Repo Settings > Pages > Deploy from branch `main`, folder `/ (root)`. The deck is then at `https://<user>.github.io/<repo>/`.

reveal.js 6.0.2 is bundled in `vendor/reveal`, so no CDN or build step is needed.
